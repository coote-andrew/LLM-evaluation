Sensitivity / specificity — ground truth values

When a check or field is flagged for sensitivity/specificity tracking in an evaluation config, the system reads the linked output_* column to determine the ground truth for each row. The following values are recognised:

Treated as positive (condition present)
{% for v in pos_values %} {{ v }} {% endfor %}

Any non-zero number is positive — e.g. 1, 2, 3 are all positive; only 0 is negative.
Any other non-empty string not in the negative list is also positive — e.g. diabetes, E11.9.

Treated as negative (condition absent)
{% for v in neg_values %} {{ v }} {% endfor %} (empty cell)

An empty or blank cell is always treated as negative.

Example — binary condition column
input_clinical_note output_has_diabetes Interpreted as
Patient has type 2 diabetes… true ✓ positive
Patient is hypertensive… false ✗ negative
No relevant conditions… (empty) ✗ negative
Dx: E11.9… E11.9 ✓ positive (non-empty value)
