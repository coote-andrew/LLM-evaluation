Choose an evaluation deliberately

  • Field match: stable JSON schema and known expected values.
  • Python evaluation: transparent deterministic logic best expressed in code.
  • LLM judge: nuanced criteria where an auditable modelled assessment is acceptable.
  • Human review: expert assessment and gold-standard creation.
