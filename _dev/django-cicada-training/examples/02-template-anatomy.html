Django template anatomy

Cicada uses Django Template Language (DTL), configured as django.template.backends.django.DjangoTemplates. It is not configured to render Jinja2 templates.

Illustrative DTL source

{% extends "base.html" %}

{% block content %}
  <h1>Run {{ test_run.id|slice:":8" }}</h1>
  {% if test_run.status == "completed" %}
    <span class="badge">Completed</span>
  {% endif %}

  <ul>
  {% for result in page_results %}
    <li>Row {{ result.test_case_row.row_number }}:
      {{ result.raw_response|truncatechars:80 }}</li>
  {% empty %}
    <li>No results yet.</li>
  {% endfor %}
  </ul>
{% endblock %}

Rendered HTML (what the browser sees)

Run 8f5e32c1

Completed
  • Row 1: Structured output is valid and includes the requested fields…
  • Row 2: The expected diagnosis is absent from the model response…

Django renders the template on the server using the view’s context dictionary, then sends plain HTML to the browser.

Vocabulary to say aloud

{{ value }}
Render a value. Django escapes HTML by default.
{% if %}
Include markup only when a simple condition is true.
{% for %}
Repeat markup for each item in a queryset or list.
|filter
Apply a display filter, such as slice or truncatechars.
{% extends %}
Reuse the shared page shell from base.html.
{% url %}
Generate a URL by named route instead of hard-coding a path.
{% csrf_token %}
Protect a state-changing browser form against cross-site request forgery.

Do not confuse DTL {{ test_run... }} rendering with Cicada prompt placeholders such as {input_note}. DTL runs while generating the web page; prompt placeholders are substituted later for an LLM request.
